# Aryan Bhusal — Portfolio

A responsive, single-page portfolio built with HTML and CSS in `index.html`. The design uses a dark navy background, cyan accents, responsive navigation, and sections for about, research, projects, experience, and contact.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. After GitHub finishes deploying, the site URL will appear in the Pages section.

## Personalize before publishing

Review the research and project descriptions in `index.html`. Replace the draft/general descriptions with verified titles, abstracts, dates, and links. No email address or publication URL has been invented.
